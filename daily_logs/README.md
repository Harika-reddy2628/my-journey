# Sentinel Daily Work Logs & Git Commit Registry

> **Purpose:** Transparent, high-signal evidence of daily technical progress and hands-on artifacts.  
> **Evaluation:** Reviewed directly by Nikhil (`[ARCHITECT]`) via GitHub commits.  
> **Rule:** Never leave a session without committing your daily log.

---

## 📂 Structure
- `TEMPLATE.md` — The standard Markdown format for every daily log.
- `YYYY-MM-DD.md` — Dedicated log for each calendar day of deep work.

## 🚀 Commit Protocol
After completing your mission and updating the log:
```bash
git add .
git commit -m "docs(daily-log): update YYYY-MM-DD work notes and reflection"
git push origin main
```
